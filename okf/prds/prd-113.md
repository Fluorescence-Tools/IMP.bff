# PRD-113: `IMP.bff` as a forward-model engine

Absorbs [PRD-112](prd-112.md), whose stage 1 (retiring the LabelLib backend) is
done and stands. Scope is **`imp.bff` alone** (owner, 2026-08-18); `imp-tricks`,
ChiSurf's structure modules and `IMP.cgmol` are out.

## What the package is

Structure + solvent + labels → **experiment-neutral quantities**: lifetime
spectra, rate constants, κ² distributions, distances, occupancies. Convolution,
IRF, pileup, counting statistics and fitting against raw data live outside.
Scoring against *structural* data (distances, as `AVNetworkRestraint` does) is in
scope; scoring against raw experimental data is not.

## What the tree says instead

Three migrations (PRD-97 FRET engine from ChiSurf, PRD-107 cgdye from
imp-tricks, PRD-109 quenching from QuEst/ChiSurf) each landed without
reconciling, so the layout records where code came from:

* **A TCSPC instrument layer** — `Decay*.cpp` + `PhotonStatistics.cpp` (1770
  lines), 11 headers, 11 SWIG interfaces, 9 test files — convolution, pileup,
  linearisation, decay fitting. Only consumer: `spectroscopy/decay.py`. Nothing
  in chisurf, quest, imp-tricks or tttrlib references it.
* **Two AV builders** over the same C++ core, identical seven-field
  `AccessibleVolume` dataclasses (`av/compute.py` arrays, from imp-tricks;
  `fret/av.py` PDB+fps, from ChiSurf, the only one exported).
* **Three distance layers** — `distance_metrics.py` and `fret/distance.py` share
  six identical function names; `BasicAV.dRmp/dRDA/dRDAE/pRDA` is a third.
* **Two κ² modules** and **two descriptions of a dye**: `fret/forster.py`
  (spectra, R0 tables) and `cgdye/io/template_cif.py` (atoms, dipole atoms,
  charges). "What is Alexa488" has two answers that never meet.
* **`RotamerEnsemble(AccessibleVolume)`** — rotamers inherit from the concrete AV
  class. That is *why* distance code works for rotamers: by inheritance, not
  design.
* **42 numba kernels** in 12 files behind a shim that silently substitutes
  orders-of-magnitude-slower Python.
* **Four subpackages contribute zero** of the 136 flat exports (`av`,
  `spectroscopy`, `restraints`, `label` — 3.8k lines).

## The model

The standard MD / statistical-mechanics decomposition. Nothing here is invented.

| | |
|---|---|
| **Dye** | the species: spectra, QY, τ₀, ε, dipole definition, steric + hydrodynamic radii, topology. **R0 is derived** from (Dye, Dye, solvent n, κ²), never supplied |
| **Label** | a Dye attached at a site, with its linker |
| **Representation** | configuration space + equilibrium + mobility. explicit (MD/CG): coordinates · Boltzmann(FF) · friction. implicit (AV): allowed region · uniform · D(r). discrete (RL): states · weights · transition rates. → **states**: positions, orientations, weights |
| **Dynamics** | how it is realised: sampled (Brownian, Langevin, MD) · ensemble (Smoluchowski) · discrete (kMC) · none. **Langevin and Fokker-Planck are the same dynamics**, sampled or as a density — the field solver is an integrator, not a rival model |
| **Photophysics** | interaction terms by arity: 1-body radiative/IC/rotational, 2-body PET and FRET, N-body multi-chromophore. Rate constants; **they add**, because the channels are parallel. **Representation-agnostic** — consumes states, so one implementation serves AV, rotamers, CG and MD alike |
| **Observables** | reductions to arrays: (amplitude, rate) pairs, distances, κ² distributions, anisotropy |

The system is assembled as **IMP decorators** (structure, `Label`, `Quencher`;
solvent model-level). **States are arrays, never particles** — a 30 000-point AV
must not become 30 000 IMP particles.

## Layout

```
dye/  label/  representation/  dynamics/  photophysics/  observables/  restraints/  io/
```

C++ mirrors it as flat one-concept headers with `internal/` for the rest — IMP's
own convention, and it scales: `kernel` has 98 flat headers, `core` 92, `atom`
74, and no IMP module nests deeper than `internal/`.

**Public surface is domain-scoped** (`IMP.bff.dye.Dye`,
`IMP.bff.dynamics.BrownianIntegrator`), IMP-style. `api.py` becomes a curated
re-export of entry points rather than a 136-name catalogue whose naming-families
regex grows with every feature.

**No numba, no numpy numerics in shipped code** — both are prototyping tools; the
42 kernels become C++, and no optional-dependency branching survives anywhere.

**No compatibility shims.** Import paths break as slices land; ChiSurf keeps
shims on its side, QuEst is fixed later.

## Stages

In-place vertical slices in dependency order. Each domain is moved, merged and
ported **in one pass**: a flat C++ namespace cannot hold two `average_distance`,
so **the port is what forces the de-duplication** rather than merely following it.

0. **Clear the ground** — the instrument layer, `spectroscopy/decay.py`, `junk/`.
1. **`dye/`** — one `Dye` carrying spectra *and* topology; dye library; R0 derived.
2. **`label/`** — `Label` and `Quencher` decorators; solvent model-level.
3. **`representation/`** — merge the two AV builders into one core with two front
   doors; cut the `RotamerEnsemble(AccessibleVolume)` inheritance; deal with
   `av/_kernels.py`. *Gate: byte-identical AVs through both doors.*
   **Done: 3a–3d.** 3a fixed a transposed density, 3b put both doors on one core
   (12/12 byte-identical), 3c introduced `States` and made rotamers a sibling,
   3d moved the label distributions out of `label/`.

   **3e was mis-scoped and is folded into stage 4.** It was written as "port
   `av/_kernels.py` to C++". The C++ *already exists*: `AV.h` exports
   `av_distance`, `av_distance_quadrature`, `av_random_points`,
   `av_random_distances` and `av_distance_distribution`, operating on `AV`
   decorators. The six numba kernels are a **duplicate** taking point arrays
   instead — so this is de-duplication, not a port.
4. **`photophysics/`** — interaction terms; merge the **six** distance layers and
   two κ² modules; port `polymer`, `distributions`,
   `quenching/{pet,maps,grids,asa}`.

   The six, found while scoping 3e: `av/_kernels.py` (numba), `av/basic.py`
   (wrapping it), `fret/distance.py`, `distance_metrics.py`,
   `representation/distribution.py` (on both concrete classes), and **the C++
   `av_distance` family**. Measured on T4L A132×A65, 2180×3087 points, 2×10⁵
   samples: `<R_DA>` 51.945 against 51.940 Å and `<R_DA>_E` 51.696 against
   51.692 Å between the numba and `fret/distance` routes, with `Rmp` identical.
   **They agree** — the spread is Monte-Carlo noise — so unlike the transposed
   density this is a clean de-duplication with no defect hiding in it, and the
   C++ is the implementation to keep.

   The work is C++ array overloads plus SWIG typemaps for a second 2-D input
   array (`BFF.types.i` defines one today), then deleting the Python copies.
5. **`dynamics/`** — integrators; port `quenching/{diffusion,photon,solver,fret_trace}`;
   delete `_jit.py`. *Gate per kernel: identical output to the numba version.*
6. **`observables/`** — reductions; state the output contract once.
7. **`io/`, `restraints/`, surface** — rebuild `api.py`; add an import-discipline
   test asserting the subpackage graph is acyclic and no domain reaches into
   another's privates.

## Non-goals

* **No physics changes.** Stage 3's gate is byte-identical AVs, stages 4–5' is
  per-kernel equality. Anything that moves a number stops the stage.
* **Nothing outside `imp.bff`.** QuEst and ChiSurf breakage is expected.
* The **exchange-regime knob** floated during design (fast vs static FRET
  averaging as a first-class switch) is **not** part of this. The arithmetic mean
  of rates and the harmonic mean are the general calculation and a static
  approximation; they get documented as such, not promoted to an API.

## How this fails

* **Stage 3 is the risky one.** Two builders with different bug-fix histories can
  differ in ways no test covers, and "byte-identical" is only as good as the
  sites it is checked on.
* **The C++ port can change answers silently.** The quenching suite (139 tests)
  pins against analytic results rather than recorded numbers, which is what makes
  it usable as the gate — but the RNG-carrying kernels (`diffusion`, `photon`)
  are pinned by seeded reproducibility, and reproducing a numba RNG stream in C++
  is not automatic.
