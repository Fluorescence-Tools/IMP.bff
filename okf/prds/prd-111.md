# PRD-111: what has to be measured

Successor to [PRD-110](prd-110.md), which stopped at its stage-0 gate. Reads
that gate's record: [`okf/validation/quenching_identifiability.md`](../validation/quenching_identifiability.md).

PRD-110 asked *how do we fit faster* and discovered it was the wrong question:
`θ = (free_diffusion, slow_factor, contact_distance, kQ_scale, rC)` is not
recoverable from one decay, so a differentiable surrogate would have made an
under-determined fit converge faster to an answer that is still wrong. The right
question is the one underneath — **what has to be measured for these parameters
to exist as quantities at all.**

## The candidate answers, cheapest first

| candidate | new physics? | new instrument? | status |
|---|---|---|---|
| **decays at several sites, one shared θ** | none | none | **stage 0, measured** |
| donor decay with an acceptor (`fret_rate_map`) | none | none | stage 1 |
| time-resolved anisotropy | orientational dynamics — the model has none | none | out of scope, named |
| FCS | the propagator, which the solver already has | correlator | stage 3, scoped only |
| reduce the model to what one decay carries | none | none | the fallback if the above fail |

The first is cheapest because it needs nothing that is not already in the model
and nothing that is not already in a lab that does site-directed labelling —
and because the arithmetic is favourable in a way worth stating plainly:

> **θ is global, the geometry is per site.** It is the same dye molecule with
> the same chemistry and the same mobility at every position; what changes is
> the protein around it. So `N` decays share one `θ`, and the joint Fisher
> information is the **sum** of the per-site matrices,
> `F = Σ_s J_sᵀ J_s`.

That sum is better conditioned than its terms **only if the blind directions
rotate with the geometry.** Six copies of one site give `6 F_s` — the same
condition number, and only a `√6` improvement in the error bars. If the
degeneracy is structural rather than geometric, no number of sites helps and the
model has to be reduced instead. Stage 0 is exactly that measurement.

## The hypothesis, named in advance so it can be disappointed

Before measuring, the mechanism to hope for was: **diffusion only matters when
the dye has to travel.** At a site with a tryptophan in the dye's immediate
contact shell, the population is quenched where it already sits and the mobility
never enters; at a site whose only quencher is 10 Å away, reaching it *is* the
rate. Two such sites should weight `free_diffusion` differently.

It is recorded here because **it was wrong**, and the way it was wrong is the
useful part — see the validation page. The directions do rotate, and the joint
matrix is well conditioned, but not by the mechanism predicted.

## Stage 0 — is θ identifiable from several sites? (measured)

`benchmark/kq_sensitivity_analysis.py`. Six chain-A sites on T4 lysozyme 3GUN,
chosen to span quencher coverage rather than for their pedigree, AV1 at 1.5 Å,
the same `θ₀`, noise model and time axis as PRD-110 stage 0 so the two are
directly comparable — and site A132 reproduces PRD-110's condition number
`1.425 × 10¹⁰` exactly, which is what makes the comparison a comparison.

**Gate: the joint condition number below 10⁴–10⁵ *and* every parameter's
marginal uncertainty below 50 %.** Neither alone is enough: a condition number
is a ratio and can be flattered by a large leading eigenvalue, and a marginal
error bar hides the correlations.

Result and full numbers: [`okf/validation/quenching_multisite.md`](../validation/quenching_multisite.md).
**The gate passes.** Joint condition number `1.8 × 10⁵`, three orders below the
best single site, and every parameter marginally determined to between 0.2 % and
7.7 %.

The rotation is real and it is the whole effect: if every site were blind the
same way, the joint matrix would be as blind as the sum of its parts
(`λ_min = 0.0456`); it is `152.7`, a **3 350× gain**. Second principal angles
between per-site blind subspaces reach `88.4°` — A132 against A19 are very
nearly complementary.

A joint least-squares fit confirms it, and is the reason to believe the
eigenvalues:

| parameter | one site (PRD-110) | six sites |
|---|---|---|
| `free_diffusion` | −52.3 % | **+2.5 %** |
| `kQ_scale` | −69.3 % | **+4.3 %** |
| `rC` | +5.5 % | **−0.2 %** |
| `slow_factor` | −4.0 % | **−2.8 %** |
| `contact_distance` | +15.0 % | **−33.4 %** |

It also converged in **97 evaluations against 676** — a well-conditioned problem
is cheaper as well as more correct, which is precisely the opposite of the
premise PRD-110 was built on.

**Two results qualify the pass, and both are actionable now:**

1. **`contact_distance` and `slow_factor` are one parameter, not two.** The
   Fisher matrix promises ±4.1 % and ±0.2 %; the fit misses by −33.4 % and
   −2.8 %, in exactly compensating directions — and reaches **reduced χ² =
   1.016**. It is not a failed fit but a second, exactly equivalent minimum,
   reproducible across resolutions (4.33 Å / 0.957 at 1.5 Å; 4.51 Å / 0.960 at
   2.0 Å). The two build the *same mobility field*: log `D` correlates at 0.927
   and the equilibrium occupancies overlap **98.7 %**. `slow_factor` applies once
   per contacting atom and `contact_distance` sets the count, so
   `slow_factor^n(contact_distance)` is invariant along a valley. **No number of
   sites separates them** — this is exact degeneracy, not stiffness. The model
   must be re-parameterised on the quantity the data determines (the field, or a
   smooth shell with one width), and **`JᵀJ` error bars must not be quoted for
   either** — a local linearisation cannot see a second minimum, and here it is
   confidently wrong about its *best*-determined parameter.
2. **The stated hypothesis was wrong.** Diffusion sensitivity tracks *quenched
   fraction*, not distance to the quencher — correlation with median
   dye–quencher distance is −0.56, the wrong sign. Transport becomes
   rate-limiting when quenching is fast enough to **deplete**, not when the dye
   has far to go. To measure mobility, label where the dye is strongly quenched.

## Stage 1 — how much of that survives model error?

The stage-0 error bars assume the field model is *exactly* right at all six
sites with one θ, and that is the assumption most likely to be false. A joint
fit is a strong lever and an unforgiving one: it converts a systematic error at
any site into a bias in a global parameter.

* Add one **site-specific nuisance parameter** (the obvious candidate is a
  per-site amplitude or an AV-geometry offset) and re-measure. If identifiability
  collapses, the multi-site answer is only as good as the geometry.
* **Re-parameterise the mobility field** so `contact_distance` and
  `slow_factor` are replaced by the single quantity they jointly determine, per
  the qualification above. Until then, fix `contact_distance` and fit
  `slow_factor` alone — fitting both is fitting a direction the data does not
  have.
* Fit **real decays**, not synthetic ones generated by the model being fitted.
  Until that is done, stage 0 measures the model's internal geometry and nothing
  about the world.
* Cross-validate: fit on five sites, predict the sixth.

**Gate: if a per-site nuisance parameter destroys identifiability, the joint fit
is measuring geometry error, and stage 2 becomes reducing the model.**

## Stage 2 — the second free observable

A donor decay **with an acceptor** reweights the same field by `1/R⁶` about the
acceptor position instead of by proximity to the quenchers, so it is a genuinely
different projection of `p(r, t)` and costs nothing new: `fret_rate_map` is
already implemented and already validated. Measure whether it adds a direction
the donor-only decays do not carry, by the same Fisher construction.

## Stage 3 — the reduced model, as the fallback

If stages 1–2 undercut the multi-site result, the honest move is not more data
but fewer parameters: name the two combinations one decay determines
(`slow_factor` against `rC`, per PRD-110), promote them to the model's actual
parameters, and fix the rest from independent measurement. This is scoped, not
started, and it is the branch stage 0's result makes *less* likely rather than
impossible.

## Non-goals

* **No surrogate, no network.** PRD-110's proposal is not revived by this
  result. A joint six-site fit costs six solves per evaluation, and whether that
  is worth amortising is a question to ask *after* stage 1, not before.
* **No anisotropy.** The model has no orientational degrees of freedom, so
  anisotropy cannot be predicted from it. Naming it as an observable would
  require a different model, which is a different PRD.
* **No new site-selection tooling.** Stage 0's sites were chosen by hand from a
  scouting script; if multi-site calibration becomes routine, *optimal* site
  selection (maximise the joint determinant over candidate positions) is an
  obvious and separate piece of work.

## How this fails

* **The synthetic-data trap.** Stage 0 fits data generated by the same model, so
  it measures identifiability under a perfect model and cannot measure anything
  else. Stage 1 exists because of this and should not be skipped.
* **Six sites is six experiments.** The result says calibration needs
  multi-site labelling, which is a real cost imposed on whoever calibrates. If
  that cost is unacceptable, stage 3 is the answer and the result still stands
  as the reason.
* **The rotation could be an artefact of `slow_factor`'s dominance.** It carries
  the leading eigenvalue at every site by two to three orders. Checked: the whole
  analysis was repeated at 2.0 Å and gives the same conclusion (joint condition
  3.04 × 10⁵, rotation gain 5 623×, largest angle 88.4°, the same three
  parameters recovered and the same pair degenerate). It is not a grid artefact.
* **A Fisher matrix cannot see a second minimum, and this model has one.** The
  `contact_distance`/`slow_factor` valley was invisible to the eigenvalues and
  obvious to the fit. Every claim on this page rests on the fit for that reason;
  the eigenvalues are the cheap screen, not the evidence.
* **A subspace-angle diagnostic can report a result that is pure arithmetic.**
  Two subspaces of dimension `r` in `Rⁿ` must intersect once `2r > n`, so a
  rank-3 comparison of five parameters returns 0° for every pair whatever the
  geometry. The first version of the benchmark did this. Rank is now capped and
  the decisive number is the eigenvalue gain, which no choice of rank can
  flatter.
