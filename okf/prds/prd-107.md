# PRD-107: cgdye consolidation — hygiene, one LJ table, strip delegation, FRETpredict parity, physics invariants, flat `IMP.bff` API

## The assertion

`IMP.bff.cgdye` is where the *explicit* dye lives — MOL2 topology, backbone-frame
labelling, linker Metropolis sampling, rotamer libraries (the FRETpredict
libraries are module data), R0-from-spectra, κ², static/dynamic FRET regimes,
the exact kinetic master equation. It is the physics reference the AV
machinery should be checked against, and the source of rotamer ensembles for
FRET-restrained docking (PRD-108). Today none of that is *pinned*: every
FRETpredict parity test skips (no FRETpredict/MDAnalysis installed, no Hsp90
fixture), and the tree carries the hygiene debt of a move (PRD-93 stage 2).
Before cgdye can serve docking it must be consolidated: parity gated, physics
invariants asserted, duplicates merged, the strip engine shared with the AV
side (PRD-106), and a flat, self-explanatory user-facing surface at
`IMP.bff.*`.

Decisions taken with the user (2026-08-17, grilling session):

1. Docking integration is Python-only for now; a C++ `R1` position type inside
   `AVNetworkRestraint` is a gated follow-on recorded in PRD-108.
2. **Hard parity gate against FRETpredict** (Hsp90, pp11), including a
   time-boxed investigation of the existing 1.1e-3 Es gap; AV↔rotamer
   differences are recorded, not gated (PRD-108).
3. Strip: the shared `fret/strip.py` engine takes a mask; **cgdye keeps
   stripping CB** (the explicit linker is built off CA and replaces the whole
   side chain), the AV convention keeps CB — per-consumer defaults.
4. De-duplication: one CHARMM36 table and one LJ kernel; delete
   `sampling/rrt.py` (unused; `rrt_imp.py`, the tested one, becomes `rrt.py`);
   the scalar energy path routes through the vectorised one;
   `segments.py`/`fp_lib.py` untouched (fpsim copies, chisurf PRD-96).
5. Fixtures: gzip'd Hsp90/pp11 PDBs and FRETpredict `.dat` outputs under
   `test/cgdye/rotamer/data/`, JSON pins with provenance in `test/references/`.
6. API: source stays organised in `cgdye/` sub-packages; the **user-facing
   surface is flat at `IMP.bff.*`** (lazy, click-free, the whole public
   surface), **hard renames**, no aliases, names in the families `Rotamer*`,
   `Dye*`, `Linker*`, `Langevin*`, `fps_*`, `forster_radius_from_spectra`,
   `kappa2_from_dipoles`; a test asserts each export has a docstring and
   matches a family.
7. Placement: R0 and κ² live in bff (`fret`); tttrlib = photon data, chisurf =
   GUI (resolves the PRD-47 R0/κ² item on the bff side); no cross-repo code
   moves.
8. Docs: `doc/manual/structure/structure_cgdye.ipynb`, README paragraph,
   `okf/cgdye.md`. Two PRDs: this one and PRD-108 (depends on it); one commit
   per stage on `dev`; never touch `../imp`; no numba/LabelLib; cgdye → fret
   only, never the reverse.

## What the code did (2026-08-17, before stage 0)

* `scripts/rotamer_hgbp1_site481.py` shipped with a **SyntaxError** (a helper
  spliced into an open parenthesised import in 1ac2073) and no test.
* `scripts/rrt_hgbp1_site481.py` used a fictional `IMP.kinematics.Sampler`/
  `RRT.set_sampler` API — it never ran; its test skipped on a stale
  `thirdparty/FRETpredict/.../A48_C1R.pdb` requirement, so nobody saw it.
* `rotamer/io.load_protein_frames` set the RMF frame with
  `RMF.SetCurrentFrame` and never called `IMP.rmf.load_frame`: **every frame of
  an RMF trajectory returned the same coordinates**. Hidden because the RMF
  test skipped on a missing fixture.
* `scripts/langevin_hgbp1_site481.py` and `dye sample-langevin` were a
  collision-gated Metropolis walk over internal DOFs (no forces, friction or
  temperature); real Langevin exists only in `sim/runner.py`.
* Skips from stale paths: `test_reference_attachments.py` (whole
  parametrisation empty), `test_rotamer_sampling.py`, `test_rrt_hgbp1_script.py`,
  `test_cgdye_integration.py` (needed a pre-built system.cif), the RMF frames
  test, the Hsp90 tests. Cheap suite: 103 passed / 14 skipped.
* `import IMP.bff.cgdye` pulled `click` through `analysis/density.py`;
  `topology/builder.py` and `sim/runner.py` too — click is a CLI dependency
  (declared in `conda-recipe/meta.yaml`), not a library one.
* `RotamerFRET.__init__` called `logging.basicConfig(filename="log")`: a `log`
  file in the working directory on every construction, root logger
  reconfigured.
* `medium_test_fretpredict_parity.py` carried an unregistered
  `@pytest.mark.expensive` under a `medium_` prefix.
* Two CHARMM36 LJ tables (`topology/dye.py::CHARMM36_LJ`, `rotamer/scoring.py::LJ_PARAMETERS`)
  and two LJ kernels; `sampling/rrt.py` imported by nothing while
  `rrt_imp.py` is the tested one; `InternalEnergyEvaluator.evaluate` a scalar
  Python pair loop next to the vectorised `evaluate_batch`.

### Stage 1 — de-duplication (done 2026-08-17)
* One CHARMM36 table and one kernel: `topology/dye.py::CHARMM36_LJ`,
  `lj_cross`, `lj_parameter_arrays`, `lj_energy(r, rmin, eps, *,
  repulsive_only, cutoff, r_floor)` (vectorised, scalars work). All three
  scorers derive from it: `sampling/scoring.py` (`lj_score` scalar front,
  `evaluate_batch`), `sampling/mean_field.py::_lj_energy_pairs`,
  `rotamer/scoring.py` (`LJ_PARAMETERS` deleted; `_scaled_parameters` reads
  the canonical table). `test_lj_single_source.py`: table equality, scalar ==
  pairwise kernel (1e-12), `compute_rotamer_score` energy == `lj_energy` on the
  same pairs (1e-12), analytic well depth / zero crossing.
* `InternalEnergyEvaluator.evaluate` is one frame through `evaluate_batch`
  (no Python pair loop; `test_scoring.py` already asserts scalar == batch).
  The Metropolis chain in `LinkerSampler.sample` stays sequential — proposal
  k+1 depends on the acceptance of proposal k — so batching across steps is
  not available without changing the algorithm.
* `sampling/rrt.py` (tuple RRT, imported by nothing) deleted; `rrt_imp.py`
  → `rrt.py` (rigid-transform RRT + the torsion RRT from stage 0).
* Latent bug fixed on the way: `rotamer/scoring._site_mask` with a *list* of
  site residues masked every residue (`set(residue_indices)` instead of
  `set(site_residue)`); callers only ever passed an int.
* `segments.py`/`fp_lib.py` headers point at chisurf PRD-96 (fpsim copies; do
  not extend here).
* Cheap suite: 193 passed / 5 skipped.

## Acceptance criteria

1. `python -m compileall -q pyext/src/cgdye` clean; every shipped file in the
   manifest and importable (stage 0 test).
2. `import IMP.bff` / `import IMP.bff.cgdye` succeed without click.
3. `pytest test/cgdye test/fret` green with skips only for optional deps
   (live FRETpredict).
4. FRETpredict parity asserted from bundled pins (Hsp90 Es 0.46766 / 0.53814
   ± tolerance recorded in the PRD; pp11 per-frame).
5. One CHARMM36 table, one LJ kernel, one RRT, one strip engine.
6. Every `IMP.bff.*` export from cgdye has a docstring and a family name; no
   aliases of the old names remain.
7. AV suites (`test_AVNetworkRestraint.py`, `test_av_lattice.py`) unchanged.
