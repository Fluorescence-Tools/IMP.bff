# PRD-109: fold QuEst's dye-diffusion PET model into `IMP.bff`

Cross-repo: `../quest` is the other side. Its own OKF already carries this
direction — [`../quest/okf/specs/imp-tricks-dedup.md`](../../../quest/okf/specs/imp-tricks-dedup.md)
states the rule ("general fluorescence machinery belongs in `IMP.bff`") and even
records that the FRET rate trace "should go upstream". What that page did *not*
scope is the model itself: it lists `dye_diffusion.py` under "stays in QuEst".
**This PRD overrides that row** on the owner's instruction (2026-08-17): bff owns
"structure + site + dye parameters → quenched decay" end to end.

## What is actually missing upstream

Measured 2026-08-17, not assumed:

* `grep -rl quench pyext/src/ src/ include/` → **no matches**. bff has no PET
  quenching of any kind.
* bff has no Brownian walk of a dye *sphere* in an accessible volume.
  `LangevinDyeSampler` (PRD-108) integrates an explicit all-atom dye under a
  CHARMM-shaped force field — a different model at a different scale, and not a
  substitute.
* bff *does* already own everything QuEst borrows around the edges:
  `AccessibleVolume`/`compute_av`, `ACV` with `slow_centers`/`contact_density`,
  `av_pair_statistics`, `random_distances`, `split_av_acv`.

So this is a **move**, not a merge: nothing upstream is being duplicated or
replaced, and the arrow stays one-way (nothing in bff may import `quest`).

## Decisions (user, 2026-08-17)

1. **Deep cut.** The model objects move too, not only the kernels:
   `SimulateDiffusion` → `DyeDiffusionSimulation`, `DonorDecay` →
   `QuenchedDonorDecay`. QuEst keeps the project schema and its validation, the
   four surfaces (CLI, web UI, Qt, RPC), scanning, run artefacts, the parameter
   catalog and the dye library.
2. **`IMP.bff` is a hard dependency of QuEst.** `arm64` is the only environment
   and the base interpreter is retired, so no no-IMP fallback is maintained.
   QuEst's `resolve_av_backend`/`available_av_backends`/LabelLib branch —
   already flagged a deletion candidate by its own OKF — go.
   **Imports stay lazy**: `import quest.core` must not pull `IMP`
   (`../quest/okf/references/known-issues.md`, the dylib conflict).
3. **Python + numba, `IMP.bff._jit`.** The moved kernels use the existing
   `njit`/`jit` shim, so `import IMP.bff` still works without numba and the
   answers are the same. A C++ port of the walk is a follow-on, not this PRD.
4. **Naming follows PRD-107**: flat `IMP.bff.<Name>`, names that say what they
   are, hard renames, no aliases of retired QuEst spellings
   (`spherePoints` → `sphere_points`, `subav` → `av_contact_mask`,
   `RDAMean`/`RDAMeanE` are already upstream as `av_pair_statistics`).
5. **The numbers may not move.** QuEst's `tests/baselines/` is the acceptance
   test: `imp_bff.json` and `labellib.json` must reproduce after the rewire,
   and every kernel moved gets an equality pin against the QuEst implementation
   *before* the QuEst copy is deleted.

## ChiSurf is the third copy — added to scope 2026-08-17 (user)

`chisurf/core/structure/av/` carries a **second, different** dye-quenching
model, and the instruction is that all of it moves too.

It is largely unreachable where it sits: `dynamic.py::simulate_trajectory`
raises `ImportError` (its `fps_.pyx` survives only in stale agent worktrees),
and `_quenching_rate_per_frame` has no caller but its own test. The reachable
half — `DynamicAV` and the `functions.py` grid kernels — is a genuinely
*different* model, not a duplicate, and worth having:

| ChiSurf | What it is |
|---|---|
| `assign_diffusion_to_grid_1/2/3` | a per-voxel diffusion coefficient (mobility) field |
| `create_quenching_map` | PET as an **exponential** in distance, per atom, no cut-off |
| `create_fret_rate_map` | an effective FRET rate per donor voxel, the **harmonic** mean over the acceptor cloud |
| `DiffusionIterator` | explicit propagation of `dp/dt = div(D grad p) - k p` |
| `DynamicAV` | the three fields plus equilibrium occupancy and donor decay |

**Two models, kept as two.** QuEst's PET is a hard contact sphere (rates adding
where spheres overlap); ChiSurf's is `kQ * exp(-(d - r_dye) / rC)`. QuEst's FRET
trace takes the arithmetic mean of the rates (a fast-exchanging acceptor);
ChiSurf's map takes the harmonic mean (a static acceptor distribution). Neither
pair is a spelling variant, and collapsing them would lose physics. What the
field model adds outright is the **equilibrium occupancy**: a flat AV density
weights every accessible voxel equally, but a dye that moves slowly near the
surface dwells there, and every average taken over the volume shifts.

## Layout

    pyext/src/quenching/
      pet.py         PET reference chemistry, per-residue interaction table,
                     quencher atom selection and quenching centres
      asa.py         sphere_points, solvent_accessible_surface (Shrake-Rupley)
      grids.py       slow_factor_grid, quenching_rate_grid, av_contact_mask
      diffusion.py   simulate_dye_diffusion (the AV-grid Brownian walk)
      photon.py      simulate_photon_trace, simulate_quenched_decay
      fret_trace.py  fret_rate_trace, fret_rate_pair_trace (per-frame)
      maps.py        mobility / PET / FRET fields on the grid   [ChiSurf]
      solver.py      GridDiffusionSolver, the explicit propagator [ChiSurf]
      dynamic.py     DynamicAccessibleVolume                     [ChiSurf]
      model.py       DyeDiffusionSimulation, QuenchedDonorDecay   [QuEst]

The rate traces landed in `quenching/`, not in `fret/distance.py` as first
drafted: they need a *trajectory*, which only this package produces, and they
are the hot inner loop of a run (`n_frames * n_acceptor`), so they are jitted
where `fret/distance.py`'s Monte-Carlo samplers are deliberately vectorised.

## Stages

### Stage 0 — `IMP.bff.quenching`: PET parameters, quencher geometry, ASA (done 2026-08-17)
`pet.py`: `PET_QUENCHING_REFERENCE` (TRP > PRO ≈ TYR > MET > HIS > CYS with
surface contact distances), `QUENCHER_ATOMS` (the redox-active moiety per
residue — indole, phenol, imidazole, SD, SG — not CB), `DEFAULT_DYE_RADIUS`,
`amino_acid_quenching_defaults(kQ_scale, slow_factor, dye_radius)`,
`normalize_amino_acid_quenching(table)`, `quencher_atom_indices(atoms, table)`,
`quencher_centers(atoms, table)`. `asa.py`: `sphere_points(n)`,
`solvent_accessible_surface(xyz, vdw, indices, ...)`.
Pins: table equality against QuEst's, ASA equality on 148l.

### Stage 1 — the grids and the Brownian walk (done 2026-08-17)
`grids.py`: `slow_factor_grid`, `quenching_rate_grid` (the additive stamp),
`av_contact_mask` (adapter over `av._kernels.split_av_acv`), with the
floor-not-truncate registration and the integer `(ng - 1) // 2` centre offset
that QuEst fixed on 2026-07-28 — **both defects were upstream's originally**,
so the fix travels with the code. `diffusion.py`:
`simulate_dye_diffusion(density, slow, dg, ...)` covering both the scalar
`slow_fact` and the per-voxel `slow_factor` grid forms, sequential and `nogil`
for the documented reasons (a seeded walk cannot be `parallel=True`).
Pins: trajectory equality for a fixed seed; grid equality voxel-for-voxel.

### Stage 2 — photon / decay Monte-Carlo, and the FRET rate trace (done 2026-08-17)
`photon.py`: `simulate_photon_trace(n_ph, k_quench, t_step, tau0, seed)` and
`simulate_quenched_decay(n_curves, decay, dt_tac, k_quench, t_step, tau0)`,
keeping the seeded-sequential / unseeded-parallel split and the OS-entropy
worker seeding (an unseeded numba run otherwise repeats itself for the life of
the process — four Monte-Carlo runs returning byte-identical results reads as
precision that is not there). `fret/distance.py` gains `fret_rate_trace` and
`fret_rate_pair_trace`, the per-frame counterparts of the static metrics it
already owns, κ²-scaled.
Pins: decay-curve and photon-histogram equality at a fixed seed.

### Stage 2b — the ChiSurf field formulation (done 2026-08-17)
`maps.py`, `solver.py`, `dynamic.py` as tabled above. Pinned against **analytic
diffusion** rather than against ChiSurf's numbers, because three of its kernels
were wrong (below). 30 tests in `test/quenching/test_quenching_field.py`.

### Stage 3 — the model objects (done 2026-08-17)
`model.py`: `DyeDiffusionSimulation` (was `SimulateDiffusion`) and
`QuenchedDonorDecay` (was `DonorDecay`) — AV construction, the slow/quench
grids, the trajectory, per-residue attribution, the decay histogram, the
acceptor AV and the FRET half. Takes plain arrays and an `AccessibleVolume`,
knows nothing about QuEst's project document.
Pins: QuEst's `tests/baselines/` reproduced through the moved objects.

### Stage 4 — QuEst rewires and deletes (done 2026-08-17)
`quest/core/dye_diffusion.py` and the general half of `quest/core/av.py`
collapse to thin adapters over `IMP.bff.quenching`; `resolve_av_backend` and
the LabelLib branch go; `quest/hosts/imp_tricks.py` goes (bff is installed, not
spliced). QuEst keeps the project schema, the surfaces, `scan`, `runs`, the
parameter catalog and the dye library.
Result: QuEst 17 failed / 689 passed → **3 failed / 663 passed**, the 3 being
PRD-105 fallout that predates this work. `resolve_av_backend` keeps one name,
`quest/hosts/imp_tricks.py` is deleted, and **36 tests stopped silently

False everywhere. Baselines regenerated with the split measured, not asserted:
86 of 98 values moved for PRD-105 alone, 12 for the waiting-time fix.

### Stage 5 — ChiSurf rewires and deletes (done 2026-08-17)
`chisurf/core/structure/av/` keeps only the ChiSurf-facing shape (`BasicAV`,
`ACV`, `DynamicAV` over `IMP.bff`) plus `parameters.py` for the
`Dye`/`Sticking`/`ProteinQuenching` groups. **2 906 lines deleted**:
`static.py` (LabelLib wrappers), `functions.py`, `dynamic.py`, `utils.py`, the

## Defects found by moving the code

Six, none of them cosmetic, each fixed on the move and pinned. Recorded here
because every one was invisible in place — the output stayed plausible.

**From QuEst**

1. **`simulate_decay_quench` raced.** It accumulated into `decay[bin_idx]` from
   inside a `prange` with a data-dependent index, which numba cannot privatise
   into a reduction. On 8 threads: sums scattered 196.73–200.61 against a stable
   serial 200.612864255 — up to **2% of the emitted intensity lost**, at random,
   run to run, and worse the more curves were averaged. Now blocked per thread
   and reduced in fixed order.
2. **`simulate_decay_quench` silently did nothing** when handed a non-float64
   output array: `np.asarray(..., dtype=float64)` copied, and the kernel filled
   the copy.
3. **The ASA neighbour test was dimensionally wrong** — `dist2 < 2 * (vdw +
   probe)`, a squared distance against an unsquared sum, so a 2.45 Å cutoff
   where 6.0 Å was meant. Nearly every occluder was missed. No downstream number
   moved: QuEst computed ASA on every quencher setup and never read it
   (`quencher_asa` has no `return` statement).

**From ChiSurf**

4. **Half the evolution was discarded.** The solver swapped its ping-pong
   buffers only on odd steps while always computing `n <- f(p)`, so every even
   step recomputed the previous one from a stale buffer. Against analytic free
   diffusion: `<x^2>/2Dt` = **0.503** before, 0.9991 after.
5. **The map builders never wrote the outer slab.** `for ix in range(-npm, npm)`
   is one short per axis — two short for an even `ng`, which is what the IMP AV
   path produces. In `assign_diffusion_to_grid_1`, the variant `DynamicAV` used,
   the output was `np.empty_like`, so that slab was **uninitialised memory** read
   back as a diffusion coefficient.
6. **The outer shell held stale population.** The 7-point stencil skips it, and
   with ping-pong buffers those voxels kept the state from two steps ago — never
   decaying, never diffusing, added into every population sum. Now zeroed, and a
   domain reaching the grid edge raises.

Plus a copy-paste slip: `update_fret_map` read the donor's radiative rate out of
the `foerster_radius` keyword, so passing a Förster radius set the rate to it.

## Non-goals

* A C++ port of the walk or of the quenching grids.
* Merging `av/` and `fret/av.py` — the two AV stacks that PRD-107 left
  side-by-side. Real, but a separate PRD.
* Changing the physics. Every number is pinned; a calibration change is a
  different PRD.
